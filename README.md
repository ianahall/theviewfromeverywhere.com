# The View from Everywhere

Static travel photography blog by Ian and Kellyn, hosted on GitHub Pages.

Live: [theviewfromeverywhere.com](https://www.theviewfromeverywhere.com)  
Repo: [ianahall/theviewfromeverywhere.com](https://github.com/ianahall/theviewfromeverywhere.com)

---

## Tech stack

Pure HTML/CSS/JS — no framework, no build step required for reading. One Python generator script assembles pages from a JSON data file.

```
index.html          — homepage (blog grid, category filter)
style.css           — all styles
app.js              — mobile menu, category filter, lightbox (shared)
blog/{city}/        — one directory per post
  index.html        — post page (generated by build.py)
  images/           — full-resolution gallery images (downloaded; see below)
  images/web/       — optimized WebP + JPEG derivatives (generated by optimize.py)
images/             — homepage hero/thumbnail images (one per city)
images/web/         — optimized derivatives of the above
our-story/          — About page
contact/            — Contact page
data/
  posts.json        — authoritative post data (source of truth for the generator)
  extract.py        — re-extracts posts.json from a Squarespace XML export
sitemap.xml         — generated by build.py
robots.txt
CNAME               — custom domain for GitHub Pages
```

## Setup (fresh clone)

```bash
git clone https://github.com/ianahall/theviewfromeverywhere.com
cd theviewfromeverywhere.com

# 1. Download gallery images (~975 MB, original resolution)
bash download_images.sh

# 2. Create web-optimized derivatives (requires Pillow + cwebp)
pip install Pillow
brew install webp        # macOS; Linux: apt install webp
python3 optimize.py

# 3. Regenerate all HTML
python3 build.py
```

After step 3, open `index.html` in a browser — everything runs locally with no server.

## Updating content

### Adding or editing a post

1. Edit `data/posts.json` directly — it is the canonical data source.  
   Each post object has: `folder`, `title`, `date`, `categories`, `card_excerpt`, `body`, `images`.
2. Run `python3 build.py` to regenerate HTML.
3. Add the hero thumbnail as `images/{folder}.jpg` (any resolution; `optimize.py` will resize it).
4. Run `python3 optimize.py` to create web derivatives.
5. Commit and push.

### Re-importing from a new Squarespace export

```bash
python3 data/extract.py path/to/new-export.xml
# Review data/posts.json for any excerpt or title overrides
python3 build.py
```

> **Note:** `extract.py` contains `EXCERPT_OVERRIDE` — short card taglines authored
> for the homepage that don't come from Squarespace. Update them there if needed.

## Image workflow

| Stage | Location | Size |
|-------|----------|------|
| Full resolution (originals) | `images/*.jpg`, `blog/*/images/*.jpg` | ~1 GB |
| Web thumbnails (homepage) | `images/web/*.{webp,jpg}` | 900 px wide |
| Web gallery (post pages) | `blog/*/images/web/*.{webp,jpg}` | 1600 px wide |

Only the `web/` directories are needed by browsers. The originals are in `.gitignore`
(after the initial download) so they don't bloat the GitHub Pages deployment.

Re-running `python3 optimize.py` is idempotent — it skips files that already exist
unless you pass `--force`.

## Deployment (GitHub Pages)

The `main` branch is deployed automatically via GitHub Pages.

### Custom domain

The `CNAME` file already contains `theviewfromeverywhere.com`.  
In your DNS provider, add:

```
Type    Name    Value
A       @       185.199.108.153
A       @       185.199.109.153
A       @       185.199.110.153
A       @       185.199.111.153
CNAME   www     ianahall.github.io
```

Then in the GitHub repo → Settings → Pages, verify the custom domain and enable HTTPS.

## Contact form

`contact/index.html` currently uses a `mailto:` link fallback.  
To wire a real form endpoint:

1. Create a free account at [formspree.io](https://formspree.io).
2. Create a new form — you'll get an ID like `xpzgkwqr`.
3. In `contact/index.html`, replace the `mailto:` section with:
   ```html
   <form class="contact-form" action="https://formspree.io/f/YOUR_ID" method="POST">
     ...
   </form>
   ```

## Typography

| Role | Font used | Original (Squarespace) |
|------|-----------|------------------------|
| Site title, card/post titles | Bitter (Google Fonts) | Jubilat (Adobe Fonts) |
| Nav, body, captions, meta | Lora (Google Fonts) | Minion Pro (Adobe Fonts) |

Both substitutes are free, open-source, and served via Google Fonts with `display=swap`.
