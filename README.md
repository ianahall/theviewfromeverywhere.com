# The View from Everywhere

Static travel photography blog by Ian and Kellyn, hosted on GitHub Pages.

Preview: [ianahall.github.io/tvfe](https://ianahall.github.io/tvfe/)

---

## Tech stack

Pure HTML/CSS/JS — no framework, no build server. One Python script assembles all pages from
per-post source files.

```
posts/
  _index.json       — ordered list of slugs (homepage display order)
  {slug}.json       — Squarespace-imported posts (generated by data/extract.py)
  {slug}.md         — hand-authored posts (new locations added after Squarespace)

blog/{city}/
  index.html        — post page (generated by build.py — do not edit directly)
  images/           — full-resolution gallery images (gitignored after download)
  images/web/       — optimized WebP + JPEG derivatives (committed; served to browsers)
  images/web/manifest.json — {stem: {w,h}} used for width/height attributes

images/             — homepage thumbnail images (one per post)
images/web/         — optimized derivatives of the above

build.py            — generates all HTML + sitemap.xml from posts/
optimize.py         — creates web-optimized derivatives from full-res originals
new_post.py         — scaffolds a new post (use this to add new locations)
data/
  extract.py        — re-extracts posts/{slug}.json from a Squarespace XML export
  posts.json        — monolithic copy of all post data (reference / backup)
style.css           — all styles (supports dark mode)
app.js              — mobile menu, category filter, lightbox, back-to-top
```

## Setup (fresh clone)

```bash
git clone https://github.com/ianahall/tvfe
cd tvfe

# 1. Download gallery images (~975 MB, original resolution)
python3 build.py --with-download-script   # regenerates download_images.sh
bash download_images.sh

# 2. Create web-optimized derivatives (requires Pillow + cwebp)
pip install Pillow
brew install webp        # macOS; Linux: apt install webp
python3 optimize.py

# 3. Regenerate all HTML
python3 build.py
```

After step 3, open `index.html` locally or push to GitHub Pages.

## Adding a new post (no Squarespace needed)

```bash
python3 new_post.py my-destination
```

This creates `posts/my-destination.md` (template to fill in) and `blog/my-destination/images/`
(drop your photos here), and adds the slug to the top of `posts/_index.json`.

### Post file format (`posts/{slug}.md`)

```markdown
title: New Zealand
date: June 12, 2026
categories:
  - Asia
hero_image: DSC_0001.jpg
card_excerpt: Middle Earth is real.
---

First paragraph of your post. You can write across
multiple lines — they'll be joined into one <p> tag.

Leave a blank line to start a new paragraph.

[gallery]
DSC_0001.jpg
DSC_0002.jpg
DSC_0003.jpg
[/gallery]

Text between gallery blocks becomes its own paragraph section.
You can alternate text and galleries freely.

[gallery]
DSC_0004.jpg
[/gallery]
```

**Rules:**
- `categories` must be one of: `Europe`, `Asia`, `Africa`, `United States`, `Parks`
- `hero_image` is the filename of the photo that appears as the full-bleed hero (must be in `blog/{slug}/images/web/` after optimize.py runs)
- Single-image galleries render full-width; two or more render as a 2-column grid
- Image filenames are matched against `blog/{slug}/images/web/` — run `optimize.py` first

### Full workflow for a new post

```bash
# 1. Scaffold
python3 new_post.py my-destination

# 2. Edit the post file
open posts/my-destination.md

# 3. Copy full-resolution photos
cp ~/Photos/trip/*.jpg blog/my-destination/images/

# 4. Create web derivatives (WebP + resized JPEG)
python3 optimize.py blog/my-destination/images

# 5. Build
python3 build.py

# 6. Commit
git add posts/my-destination.md posts/_index.json blog/my-destination/
git commit -m "Add my-destination post"
git push
```

## Editing an existing post

All 33 existing posts live as JSON files in `posts/`. They are fully editable:

```bash
open posts/london.json      # edit title, text blocks, gallery order, etc.
python3 build.py            # rebuild
```

Fields in a post JSON file:
| Field | Description |
|-------|-------------|
| `title` | Display title |
| `date` | Human-readable date (e.g. "May 2, 2017") |
| `date_iso` | ISO date for sitemap/SEO (e.g. "2017-05-02") |
| `categories` | Array of category strings |
| `card_excerpt` | Short tagline shown on the homepage card |
| `hero_image` | Filename of the hero photo (from `blog/{slug}/images/`) |
| `blocks` | Ordered array of `paragraph` and `gallery` blocks |

## Re-importing from a Squarespace XML export

If you ever re-export from Squarespace (e.g. to pick up edited posts):

```bash
python3 data/extract.py path/to/export.xml
# This overwrites posts/{slug}.json for existing posts
# and writes any new posts discovered in the export.
# Hand-authored posts/{slug}.md files are NOT affected.
python3 build.py
```

> **Note:** `data/extract.py` contains `EXCERPT_OVERRIDE` — card taglines that override
> Squarespace's auto-generated excerpts. Update them there if you add new slugs via export.

## Image workflow

| Stage | Location | Notes |
|-------|----------|-------|
| Full resolution | `blog/{slug}/images/*.jpg` | Gitignored; re-download with `download_images.sh` |
| Web gallery | `blog/{slug}/images/web/*.{webp,jpg}` | Committed; 800w + 1600w |
| Web thumbnail | `images/web/*.{webp,jpg}` | Committed; 480w + 900w |

`optimize.py` is idempotent — it skips files that already exist unless you pass `--force`.

To add a homepage thumbnail for a new post, put the source image at `images/{slug}.jpg`
and run `python3 optimize.py images/`.

## CDN image URLs

Each post imported from Squarespace has `src_url` fields pointing to the original CDN URLs.
These are the source of truth for `download_images.sh`. If you cancel your Squarespace
account, these URLs will stop working — but the local files already committed as
`blog/*/images/web/*` are the durable copy used by the live site.

## Deployment (GitHub Pages)

The `main` branch deploys automatically via GitHub Pages.

### Custom domain

When ready to point `theviewfromeverywhere.com` at this repo:

1. Add a `CNAME` file at the repo root containing `theviewfromeverywhere.com`
2. Rename the GitHub repo from `tvfe` back to `theviewfromeverywhere.com`
3. In your DNS provider, add:

```
Type    Name    Value
A       @       185.199.108.153
A       @       185.199.109.153
A       @       185.199.110.153
A       @       185.199.111.153
CNAME   www     ianahall.github.io
```

4. In GitHub repo → Settings → Pages → verify custom domain and enable HTTPS.

## Typography

| Role | Font |
|------|------|
| Site title, card titles, post titles | Newsreader (Google Fonts) |
| Nav, body, captions, meta | Lora (Google Fonts) |

Fonts load with `display=optional` — if cached, they appear immediately; if not, the browser
falls back to Georgia for the first load rather than causing a layout shift.

## Contact form

`contact/index.html` uses a `mailto:` fallback. To wire a real form:

1. Create a free account at [formspree.io](https://formspree.io).
2. Create a form — you'll get an ID like `xpzgkwqr`.
3. In `contact/index.html`, set `action="https://formspree.io/f/YOUR_ID"` on the `<form>` tag.
